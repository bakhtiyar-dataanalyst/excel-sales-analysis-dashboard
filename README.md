# Excel Sales Analysis Dashboard

Cleaned a messy 314-row retail sales dataset and built an interactive analysis dashboard in Excel.

## What was done
- Cleaned data using Power Query: removed duplicates and blank rows, standardized inconsistent text (case/spacing), fixed currency-formatted values, and resolved a column with three different mixed date formats using conditional logic
- Used XLOOKUP to pull Regional Manager names from a separate reference table
- Built 3 Pivot Tables: Sales by Region, Profit Margin by Category, Average Profit by Discount Range
- Added an interactive Pivot Chart and slicers for dynamic filtering

## Key findings
- West region drives ~49% of total sales
- Technology holds a 20.6% profit margin; Furniture is unprofitable overall (-7%) due to heavy discounting
- Average profit drops sharply as discount increases
